## Методичка «Побудова блок-схем алгоритмів» (Практична робота №1, Луб, Тригуба, 2022)

**Лінійний алгоритм (с. 8), №8:**

A = (α₁β₁ − α₂β₂) / (m·α₁ − α₂²),
де α₁ = sin 0,18; β₁ = e^α₁; α₂ = ln 0,05 + e^α₁; β₂ = 1,7.
*(m у методичці не задано — вводиться як вхідний параметр.)*

**Розгалужений алгоритм (с. 10), №8:**

Y = x·(A − C)³, якщо A = C, x = A;
Y = x³ − A,     якщо A ≠ C;
Y = x + A³,     якщо A = C, x = A.
*(Перша і третя умови в методичці однакові — ймовірно, друкарська помилка; треба уточнити або явно задокументувати трактування.)*

**Циклічний алгоритм (с. 18), №8:**

yᵢ = (a·xᵢ + 4b + c)³, b = 5a + c; a = 2,5; c = 0,2; i = 1, 2, 3 … 25.
*(xᵢ не задано — вводиться масив або генерується.)*

**Зовнішні процедури (с. 23), №8** — виділити підпрограму:

z = tg(1 − a·x)², якщо x ≥ 3y;
z = tg(1 − a·y)², якщо x < 3y;
x = 1,5; y = 2,5; a = 0,3.
→ підпрограма `f(t) = tg(1 − a·t)²`.

## Методичка «Способи подання алгоритмів та реалізація лінійних алгоритмів» (Лаб. №2, 2023)

**Способи подання алгоритмів, №8:**
Записати у вигляді блок-схеми алгоритм перевірки, чи можна з трьох відрізків a, b, c побудувати трикутник.

**Реалізація лінійних алгоритмів, №8:**
Дано координати трьох вершин трикутника (x1, y1), (x2, y2), (x3, y3). Використовуючи формулу відстані між двома точками, знайти периметр і площу.
Вхідні дані: x1 = 0, y1 = 0, x2 = 0, y2 = 3, x3 = 4, y3 = 0. Результат: P = 12, S = 6.
