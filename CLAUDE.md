# Daniel_portfolio — інструкції для AI

## Що це за проєкт
Портфоліо-сайт + API для здачі звітів з лабораторних робіт з дисципліни
«Основи програмування» / «Алгоритмізація та програмування» (ЛНУП, кафедра ІТ,
викладач: к.т.н., доц. Луб Павло Миронович).

Звіти здаються **не файлом, а текстом через API-запит**: викладач отримує посилання
на API-ендпоінт (студент кладе його в Moodle, папка «Звіти...») і робить GET-запит.
Мета — показати, що основи програмування для автора занадто легкі.

Код буде розгорнуто на віддаленому сервері.

## ⚠️ ВАРІАНТ = 8
У **всіх** індивідуальних завданнях / завданнях для самостійної роботи робимо
**тільки завдання №8** (номер студента в списку групи). Якщо в методичці є
список варіантів — беремо пункт 8 і нічого іншого. Якщо в роботі немає варіантів
(завдання спільне для всіх) — робимо спільне завдання.

## Стек
- **Backend:** Python 3.11, Django + Django REST Framework (`backend/`)
- **Frontend:** React + Vite + TypeScript (`frontend/`)
- Мова інтерфейсу та звітів: українська.

## Як влаштовані звіти
- На перших роботах викладач просить **не програму, а модель** (блок-схему) + коротко
  «чого навчились». Ми робимо більше: інтерактивну модель.
- **Один файл методички = один звіт = один API-запит + своя сторінка демо.**
  | Методичка | slug | API |
  |---|---|---|
  | Побудова блок-схем алгоритмів (PDF) | `lab-1` | `/api/reports/lab-1/text/` |
  | Способи подання алгоритмів… лінійних алгоритмів (.doc) | `lab-2` | `/api/reports/lab-2/text/` |
  | Робота в ІСР MS Visual Studio + ввід/вивід (PDF) | `practice-1` | `/api/reports/practice-1/text/` |
- Контент звітів лежить у `backend/reports/content/*.json` → `python manage.py load_reports`.
- Якщо завдання — «написати програму», додаємо `code` + `output` (C++). Компілятора на машині
  немає, тож математику перевіряємо тестами інтерпретатора.
- Кожне завдання має `model` — JSON блок-схеми (nodes/edges у координатах символів).
  З **однієї** моделі рендериться:
  - ASCII-схема в `GET /api/reports/<slug>/text/` (`backend/reports/flowchart.py`);
  - анімований SVG на сторінці `/labs/<slug>` (`frontend/src/flow/`).
  Геометрія в `flowchart.py` і `geometry.ts` має бути ідентичною — міняєш одну, міняй іншу.
- Вирази в блоках — власна мова (`frontend/src/flow/expr.ts`): `+ - * / ^`, `x[i]` (1-based),
  `== != < <= > >=`, `and/or/not`, `sin cos tan exp ln lg sqrt abs`. Жодного `eval`.
- Текстовий звіт закінчується посиланням на інтерактивну сторінку (`FRONTEND_URL`).

## Команди
- Backend: `cd backend && venv/Scripts/python manage.py runserver` · тести: `manage.py test reports`
- Frontend: `cd frontend && npm run dev` (проксі `/api` → :8000) · тести: `npm test` · типи: `npm run typecheck`

## Структура звіту (за зразком викладача)
1. Титулка: Міністерство освіти і науки України; університет; факультет механіки,
   енергетики та ІТ; кафедра інформаційних технологій; «ЗВІТ з виконання
   лабораторної роботи №N з дисципліни «Основи програмування» на тему: «...»»;
   Виконав: студент групи ..., ПІБ; Перевірив: к.т.н., доц. Луб П.М.; місто, рік.
2. Мета роботи.
3. Загальні відомості (короткий конспект теорії).
4. Завдання 1..N (варіант 8): умова → блок-схема / алгоритм → код → результат.
5. Висновок.
